How it works

Input → Validation → Decision → Evidence

All training and validation splits are by engine. Model selection and the threshold sweep use validation engines. The first-five-cycle drift reference now uses only observations available at each cycle.

Test trajectories are truncated. Engines that never enter the policy danger window during observation are counted as censored, rather than as demonstrated eventual successes.

FD001 is a previously explored public benchmark. These corrected results are not new external safety validation; fleet deployment requires prospective evaluation and operational review.
